# 《重生末日之前》机制设计 v0.3

> 一句话：**女主死后重生到末日前一个月，靠前世记忆囤货、建基地、打丧尸、种田、谈恋爱活下去。**
> 骨架借鉴《苏丹的游戏》（限期危机卡 + 地图放卡 + 属性=骰子数的检定 + 多线结局），表皮和系统完全是末日重生文。
>
> v0.3 变更：序章改为末日前 4 周（重生点可买到 48 周）；稀有度改为 **普通/优良/稀有/传说**（白/绿/蓝/金）；三属性 **体力/头脑/魅力**；去掉心态数值；加入丧尸、晶核、异能、基地模块、伙伴忠诚、外交、宠物、重生点商店；男主阵容重做。

## 0. 骨架（借鉴项，不对外强调）

| 骨架 | 本作对应 |
|---|---|
| 限期压力卡 | **月度危机卡**：每月初抽 1 张，月末必须顶住 |
| 地图 + 事件 + 卡槽 | 地点 → 事件 → 把人/物放进槽位 |
| 属性 = 骰子数 | 三属性相加掷骰，数成功数 |
| 天→周→局 | **周 → 月 → 年 → 一世** |
| 多线结局 + 多周目 | 男主结局 + 重生点商店 |

## 1. 世界与基调

- **舞台**：架空的现代城市"临江市"。**枪极难买**：序章里只有黑市高价（几万一把）或有门路（军方/佣兵）才能拿到；冷兵器、弩、改装工具是主流武器。
- **末日**：**丧尸末日**。病毒爆发后一周内城市失守。之后每年叠加新的灾难（极寒、暴雨、高温、变异）。
- **重生**：女主林知夏第一世在末日第 3 年死于尸潮。睁眼回到末日前 4 周。她记得前世前两年每个月的大事，但改变越多记忆越不准（蝴蝶效应）。
- **基调**：写实、残酷、有温情。允许女主死亡（进入下一世）、伙伴与男主死亡（本世永久）。无血腥特写，无成人内容。
- **语言**：中文优先，所有文案 `{ zh, en? }`，UI 字符串走 i18n。

## 3. 时间结构

```
一世
 ├─ 序章 · 末日前：默认 4 周（重生点可买到最多 48 周）
 └─ 末日后：第 1 ~ 10 年，每年 12 个月，每月 4 周
       └─ 一周 = 1 回合：
            1. 周初：结算上周事件、扣消耗（吃喝、宠物、伙伴）、过期、新闻
            2. 本周：女主选 1 件事做；伙伴各派 1 件事；建造/训练/交易
            3. 过一周
       └─ 月初抽危机卡，月末结算
       └─ 年末：年度大事件 + 年度结算（存档带入下一年）
```

- **第一版范围：序章 4 周 + 末日第 1 年（48 周）**，合计 52 回合，目标 90 分钟一世。
- 第 2~10 年只定方向（见第 12 节），系统逐年追加。

## 4. 序章：末日前 4 周

目标：**用尽一切办法搞钱，把钱换成活下去的东西**。

### 4.1 搞钱（按风险排）
| 手段 | 说明 | 代价 |
|---|---|---|
| 打工 | 每周固定工资 | 占用一周 |
| 卖房卖车卖首饰 | 一次性大额 | 蝴蝶效应 +（家人起疑） |
| 信用卡 / 网贷 / 抵押 | 末日后债务作废（经典梗）。额度按头脑和魅力检定 | 序章内每周利息；被拒后不能再借 |
| 炒股 | 记忆里有 3 只股票，一只比一只记得模糊：投 1 万 / 3 万 / 10 万，头脑检定 | 每只蝴蝶 +8/+10/+15，赚多了券商和别人会盯上你（暴露） |
| 彩票 | 需要开局特质"记得中奖号码"（6 点）。兑奖两周，税后 400 万 | 蝴蝶 +30，暴露 +40，亲戚上门借钱（每周 -5000、暴露 +3，需换号搬东西才解决），前任找上门，末日后黑鸦关系 -20 |
| 提前接触男主 | 找到未来的大佬，送东西/示警 | 他们现在不信你，好感涨得慢，但末日后回报巨大 |

### 4.1b 网购 vs 线下（v0.4）
- **网购**（仓库页）：手机下单不耗精力；下周到货，大件（发电机、钢材、水泥、净水器、复合弩）两周；运费加一成；每件每周限购（默认 5，发电机/弩 1）；枪和生鲜买不到。**末日一到，在路上的快递全部丢失。**
- **线下**（地图事件）：亲自去搬，耗精力和一周，当场到手，有机会拿到更便宜或不上架的货（超市仓库直销、五金店现货发电机、黑市的枪、军品店）。

### 4.2 花钱
- **物资**：食物、水、药品、能源、武器、材料、日用（7 维度，见 6.1）。
- **武器**：冷兵器（砍刀、消防斧、长矛）、弩、防具。枪：黑市传说级价格，或通过顾沉/江野线的门路事件。
- **换房（基地）**：出租屋（默认）→ 别墅 → 郊区自建房 → 地下堡垒。见第 7 节。
- **加固与模块**：按基地类型建。
- **宠物**：收养狗/猫。
- **空间**：女主的空间异能在序章就有（普通档），升级要晶核，序章升不了。

### 4.3 序章结束：末日降临
第 4 周末固定事件"病毒爆发"。检定女主准备度（基地防御 + 武器 + 食水），分档决定第 1 年 1 月的开局状态（伙伴是否受伤、物资损失、是否被迫转移）。

## 5. 末日后：一周做什么

- 地图分两层：**基地内**（建造、训练、看书、守卫、种田、宠物、伙伴对话）与**外出**（搜刮地点、其他基地、剧情地点）。
- 女主每周 1 件事；每个伙伴每周 1 件事（守卫 / 种田 / 搜刮 / 训练 / 陪同）。
- 外出事件有**遭遇**：随机丧尸、幸存者、其他势力。
- 事件耗 1~2 周，下周初结算。

### 5.0 精力（v0.4 新增）
- 女主每周有**精力**，上限 = 3 + 体力/2 + 永久加成（开局 4 点）（特质、高剂量维生素）。每个事件标精力消耗：打电话/串门/看书 1，上班/采购/搜刮 2，摸军械库/拆工厂/搞发电机 3。
- 精力够就能一周做几件事；伙伴参与不耗女主精力。
- 咖啡（+1）、功能饮料（+2）临时加本周精力；维生素永久 +1 上限。受伤停工时精力为 0。

### 5.0b 突发选择事件（v0.4 新增）
- 每周初 50% 概率弹出一个"突发"：2~3 个选项当场结算（可带检定），不占槽位、不耗精力。必须处理完才能过周。
- 例：邻居借米、"查燃气的"敲门、楼下的哭声、伙伴袖子上的血、走街串巷的贩子。

### 5.1 检定
三属性：💪**体力** / 🧠**头脑** / 💬**魅力**。
**检定 = 掷（2 基础骰 + 属性A + 属性B + 装备/物资/异能加成）个骰子，每骰 50% 成功：**
0 成功 = 失败 / 1~2 = 普通 / 3~6 = 优良 / 7~8 = 稀有 / ≥9 = 传说（事件可自定传说线）。属性成长有递减：3 以下必涨，之后每次 +1 的概率 = 3/当前值。
带队的人算全属性；"带个人"槽里的同行者只算一半属性。开局属性 3/3/3（偏向型 5/2/2）：单属性检定 5 骰 → 失败 3%、普通 47%、优良 47%、稀有 3%；双属性 8 骰 → 失败 0.4%、普通 14%、优良 71%、稀有 14%。

### 5.2 属性成长（所有人）
- 训练（体力）、看书（头脑）、社交/演讲（魅力）：基地事件，每次检定成功 +1，上限 10。
- 事件也能减属性：重伤 −体力，精神打击 −头脑，声名狼藉 −魅力。
- 人物稀有度决定初始属性总和：普通 4 / 优良 6 / 稀有 8 / 传说 10。

## 6. 卡牌与物资

### 6.1 物资 7 维度
| 维度 | 例子 | 用途 |
|---|---|---|
| 食物 food | 大米、压缩饼干、罐头 | 每周消耗；顶匮乏 |
| 水 water | 矿泉水、净水片 | 每周消耗；顶匮乏/疫病 |
| 药品 medicine | 抗生素、退烧药、疫苗原料 | 顶疫病；治伤 |
| 能源 energy | 汽油、太阳能板、发电机 | 顶气候；模块运转 |
| 武器 weapon | 砍刀、弩、猎枪、防具 | 顶尸潮/人祸；外出检定加骰 |
| 材料 material | 钢材、木材、水泥、零件 | 建造模块 |
| 日用 daily | 保暖衣物、卫生用品、燃料 | 顶气候；伙伴忠诚 |

- **保质期**：食物/药品按周计，过期降一档，再过期变垃圾占位。**生鲜（蔬菜 2 周、鸡蛋 4 周）买不到，只由菜箱/菜地/畜栏产出**；有电就有冰箱，短保质期（≤8 周）翻倍：序章一直有电，末日后要有太阳能板、发电机房、柴油发电或冷库。
- **仓库**：基地仓库格数 + 女主空间格数。空间里的东西抢不走、不被搜出，但**当众使用涨暴露**。
- **份数**：食物/水卡带"份数"（人·周），一袋 5kg 大米 = 5 份。每人每周吃 1 份食物 + 1 份水；每只宠物 1 份食物。缺了掉健康/忠诚。

- **种子**（第 8 维度，不顶危机）：蔬菜种子 / 土豆种薯 / 温室种苗。菜箱、菜地、大田、温室、种植舱开工必须消耗对应种子。序章能网购，末日后只能去农场找。

### 6.1b 送礼规则
人物页点"送礼"，列出仓库里能送的东西并直接显示涨多少：物资 = 他缺的维度 5×档位、否则 2×档位；装备 3×档位；晶核 2×档位。男主涨好感，伙伴翻倍算忠诚。送出去的东西没了。

### 6.2 其他卡
- **装备卡**：占身上槽位（武器 / 防具 / 饰品），带随机词缀（消音、加固、耐用、带血）。
- **晶核卡**：击杀丧尸掉落，四档。用途：升级异能、末日后的硬通货、部分模块能源。
- **情报卡**、**技能卡**（异能/男主专属）、**麻烦卡**（负面，需处理）、**危机卡**。

### 6.3 货币
- 序章：钱。
- 末日后：钱作废。**晶核 + 物资**以物易物，各势力汇率不同。

## 7. 基地

四种基地，各自有**独立的可建模块表**，不共用。基地有 **防御值**（基础 + 模块）、**仓库格**、**人口上限**。

| 基地 | 序章价格 | 基础防御 | 仓库 | 人口 | 可建模块（首版） |
|---|---|---|---|---|---|
| **出租屋** | 默认 | 2 | 60 | 4（客厅通铺 +2） | 加固门窗、储物间、客厅通铺、阳台菜箱、太阳能板、接雨水、楼道路障 |
| **别墅** | 300 万 | 6 | 200 | 10 | 围墙、铁门、前后院菜地、阳光房温室、水井、发电机房、车库工坊、客房医务室、犬舍。贵，但样样都好：去哪都近，网购当周到 |
| **郊区自建房** | 150 万 | 4 | 150 | 8 | 围栏、瞭望塔、大田、温室、畜栏、水塔、柴油发电、仓库、医务室、训练场。便宜在偏远：进城做事每事件 +1 精力，序章网购 +1 周 |

原则：**越贵越好**。同一维度上贵的基地不会输给便宜的。
| **地下堡垒** | 2000 万 | 12 | 400 | 20 | 通风净化、水循环、冷库、武器库、实验室、无线电室、种植舱、隔离舱、秘密出口 |

- 模块建造消耗**材料分**（木板 1 分、钢材 2 分、水泥 2 分，即"材料"维度物资的稀有度分）+ 开工 1 点精力 + 周数；一次只能建一个，完工后才生效。基地页会显示现有材料分和还差多少。
- 每个模块提供一项能力：防御、产食物、产水、产能源、治疗、训练加骰、隔离顶疫病、无线电解锁外交等。
- 基地可以**迁移**（剧情事件或主动），迁移是一次大检定，可能丢物资和人。

## 8. 月度危机卡（五类 × 四档）

| 类型 | 顶住需要 | 普通 → 传说 |
|---|---|---|
| 🧟 **尸潮** horde | 防御值 + 守卫战力 + 武器分 | 零星游尸 → 小股尸群 → 尸潮 → 异能丧尸领军 |
| 🍞 **匮乏** scarcity | 食物 / 水 | 断供 → 缺水 → 饥荒 → 颗粒无收 |
| ❄️ **气候** climate | 能源 / 日用 | 降温 → 暴雨 → 极寒/高温 → 气候剧变 |
| 🦠 **疫病** plague | 药品 / 隔离舱 | 感冒 → 感染者混入 → 病毒变异 → 基地内爆发 |
| 🔥 **人祸** human | 武器 / 防御 / 势力关系 | 小偷 → 匪帮勒索 → 其他基地突袭 → 全面战争 |

**顶住方式**：硬顶（分值够）/ 借力（男主或伙伴的技能卡）/ 剧情解（本月专属事件）。
**顶不住**：普通 = 丢物资；优良 = 女主或伙伴受伤；稀有 = 伙伴死亡 / 模块损毁 / 被迫迁移；传说 = **女主死亡，本世结束**。

## 9. 丧尸、晶核、异能

- **丧尸逐年进化**：第 1 年普通丧尸 → 第 2 年敏捷/力量型 → 第 3 年起异能丧尸 → 后期丧尸王。
- **晶核**：击杀掉落，档位随丧尸等级。升级异能、交易硬通货。
- **异能**：四档。女主 **空间**：普通 = 6 格随身空间 → 优良 = 小房间 30 格 → 稀有 = 仓库 100 格、可放活物 → 传说 = 灵泉治病、时间流速 1:3（可在里面种田）。传说档第一版不做。
- 男主各有异能；普通幸存者 5% 觉醒（随机）；异能卡放进事件白槽加骰或改变结果。
- **暴露值** 0~100：当众用空间/异能、炫富、大额交易都会涨；不出风头每周 −1。序章 ≥60 招小偷（突发"有人撬门"）；末日后 ≥50 有人打听、人祸危机档位 +1；≥80 黑鸦绑走伙伴要赎金（突发"黑鸦的绑票"：交赎金 / 带人抢回 / 找顾沉 / 不管）。

## 10. 人

### 10.1 女主
三属性 + 健康 0~10 + 暴露 0~100 + 蝴蝶效应 0~100 + 空间等级。健康归零死亡。

### 10.1b 父母（v0.4 新增）
序章"跟爸妈说清楚"检定成功后，父母搬来同住并带资金（3 万 / 10 万），序章可作为伙伴派去采购、买药、买材料，末日后是稳定的两名伙伴（爸爸体力 3，妈妈头脑魅力 3）。他们也吃饭，也会死。

### 10.2 伙伴
- 来源：剧情收容、随机遭遇（随机生成：名字不重复、稀有度、三属性、1 个特质、5% 异能、1 个"缺的维度"）。**想加入的人先进"候选"列表，由玩家接受或拒绝**；接受受基地人口上限限制（出租屋 4 人含你 / 别墅 6 / 自建房 12 / 堡垒 20）。
- **忠诚 0~100**：吃饱、有装备、被信任 → 涨；挨饿、受伤、女主偏心 → 掉。<30 可能偷东西跑路或投敌；>80 解锁个人事件。
- 每周派工：守卫 / 种田 / 搜刮 / 训练 / 陪同。
- 会死。

### 10.3 男主（5 位，先做 3 位：顾沉、沈砚、谢临）

| 男主 | 身份 | 异能 | 前世 | 这一世的线 | 专属结局 |
|---|---|---|---|---|---|

**反派**：前世渣男周明宇（带着一个匪帮基地回来）、白莲花闺蜜苏媛（混进军区）。

### 10.4 恋爱
- 好感 0~100，5 档：陌生 0 / 熟人 20 / 朋友 40 / 暧昧 60 / 恋人 80。
- 涨法：同行事件、送他缺的东西（东西没了）、专属剧情。**跨档（20/40/60/80）只能靠他的剧情事件**，送礼、同行、关怀只能推到门槛前一格。序章男主不信你，最多到熟人（江野到暧昧前）。
- 解锁：朋友 = 技能卡、可派遣；暧昧 = 可入住基地；恋人 = 借力顶卡 + 专属结局。
- **多线允许**：两人同时 ≥暧昧触发修罗场（魅力+头脑检定），失败双掉，大成功进"默契"（可走多人结局）。

## 13. 随机性

- **事件牌堆**：每个地点一副，按阶段/月份/flag 加权，每周抽 2~4 张展示。剧情事件固定插入。
- **掉落表**：搜刮、战斗、交易按稀有度权重出货。
- **装备词缀**：随机 0~2 条。
- **随机幸存者**：名字、稀有度、属性、特质、异能生成。
- **危机偏移**：类型与档位在记忆基础上按蝴蝶效应偏移。
- **检定**：掷骰。
- 全局 seeded RNG，种子写在存档里。

## 13b. 开局特质（v0.4 新增）
- 正面特质花点数（健壮 2、聪明 2、精力旺盛 3、空间更大 4、囤货癖 1…），负面特质给点数（体弱 +2、社恐 +2、易疲劳 +3、网贷缠身 +2、刚被裁 +2…）。
- 第一世预算 0，只能收支平衡；每过一世 +1，重生点商店也能买。

## 14. 重生点与多周目

- **重生点**来源：存活周数、击杀晶核、达成结局、剧情里程碑。
- **商店**：序章延长 +4 周（价格递增，最多到 48 周）/ 初始资金 / 空间起始档 / 属性点 / 某男主初始好感 +20 / 初始宠物 / 带一件装备到下一世（传说档解锁）。
- 死亡画面 = "再一次睁开眼"。
