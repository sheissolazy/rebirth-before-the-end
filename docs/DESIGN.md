# 《重生末日之前》机制设计 v0.2（已敲定）

> 一句话：**《苏丹的游戏》的骨架（每回合一张"必须限期解决的卡"+ 地图放卡 + 骰子检定 + 多线结局），题材换成"女生重生回末日前一年，靠前世记忆囤货、求生、谈恋爱"。**
>
> v0.1 → v0.2 变更：时间改为 **周→月→年** 三层（12 个月一轮，共 10 轮 = 10 年，先做第 1 年）；加入**重生记忆**机制；**允许死亡**，尽量真实；**允许多线**，可攻略对象暂时只有男性；只做中文但结构上**随时可加英文**。

---

## 0. 参考作品机制拆解（已核实）

| 苏丹的游戏 | 机制要点 |
|---|---|
| 苏丹卡 | 每周抽 1 张，分 杀戮/纵欲/奢靡/征服 四类，石/铜/银/金 四档。7 天内必须"折卡"（做一件同类且品质≥卡的事），否则斩首。 |
| 回合 | 以天为单位，每天把卡放进地图事件的槽位，事件耗 1~N 天，次日清晨结算。 |
| 卡牌 | 苏丹卡、人物卡、思潮卡、消耗品、部队、情报、装备、书籍、食物…共 10 类，都分四档品质。 |
| 检定 | 骰子数 = 相关属性之和，数成功数；成功数分档给不同结果。 |
| 结局 | 多条主线，多周目解锁。 |

**我们抄的骨架**：限期压力卡、地图+事件+卡槽、属性=骰子数、三层节奏、多线结局。
**我们换掉的**：宫廷→末日前后的城市；杀人纵欲→囤货、修窝、谈恋爱；斩首→"没撑过这个月"。

## 1. 题材与基调

- **主角**：林知夏（名字可改），26 岁上班族。第一世在末日第 3 年冻死在废弃地铁站。睁眼回到末日前一年的 1 月 1 日。
- **重生 = 核心叙事装置**：她记得第一世这一年每个月发生了什么（大致），所以能提前囤。但她的行为会改变时间线（**蝴蝶效应**），记忆越用越不准。
- **世界观**：末日**渐进式**到来，不是一夜丧尸，尽量写实：物价、断供、停电、疫病、治安崩坏、极端气候、社会重组。
- **恋爱**：可攻略对象暂时只有男性，5 位。允许多线，但多线有代价（修罗场、信任）。
- **基调**：**写实 + 压抑中带温情**。允许死亡：主角死 = 本世结束（进入下一次重生）；NPC 死 = 本世永久。不做血腥特写，无成人内容。
- **语言**：中文优先，所有文案走 `{ zh, en? }` 结构，UI 字符串走 i18n 字典，随时可加英文。

## 2. 时间结构（已敲定）

```
一世（10 年 = 10 轮）
 └─ 一年（12 个月）：每年一个大主题，年末一个"年度大事件"
      └─ 一个月（4 周）：月初抽 1 张【危机卡】，月末结算
           └─ 一周 = 1 回合：
                1. 周初：结算上周事件，发新闻/消息，扣本周消耗（吃喝、房租按月）
                2. 本周：把 主角卡 / NPC 卡 / 物资卡 放进地图事件的卡槽（主角一周只能做一件事）
                3. 点"过一周"
```

- 一年 = 48 回合，目标一年 60~90 分钟。
- **先做第 1 年**（末日前夜），跑通后再做第 2~10 年。存档带跨年。
- 10 年主题（只定方向，第 1 年细化）：

| 年 | 主题 | 世界状态 |
|---|---|---|
| 1 | **前夜** | 表面正常，物价缓慢异常，钱还能用；年末"末日降临" |
| 2 | 崩塌 | 断供断电，钱作废，以物易物，治安崩坏 |
| 3 | 严冬 | 极端气候，死守 or 迁徙 |
| 4 | 据点 | 建立小据点，招人，分工 |
| 5 | 冲突 | 据点之间的资源冲突 |
| 6 | 枯竭 | 存货耗尽，必须种/养/造 |
| 7 | 秩序 | 贸易、规则、领袖 |
| 8 | 重建 | 修复基础设施 |
| 9 | 新威胁 | 外部势力 / 气候剧变 |
| 10 | 终局 | 多结局 |

## 3. 第 1 年详细设计（MVP 范围）

### 3.1 月度危机卡（= 苏丹卡）

每月初抽 1 张，**4 周内必须"顶住"**，月末结算。

四类 × 四档：

| 类型 | 对应囤货维度 | 石 → 金 |
|---|---|---|
| 🍞 **匮乏** scarcity | 食物 / 水 | 限购 → 断水两天 → 全区断供 → 饥荒 |
| ❄️ **气候** climate | 能源 / 日用（保暖） | 降温 → 停电一晚 → 暴雪封路 → 极寒 |
| 🦠 **疫病** plague | 药品 / 水 | 流感 → 邻居确诊 → 封控 → 你自己倒下 |
| 🔥 **动荡** unrest | 安全 / 日用 | 小偷 → 楼道被撬 → 暴徒扫楼 → 武装抢劫 |

**第 1 年的 12 张卡是"半固定"的**（这就是重生记忆）：

| 月 | 前世记忆 | 类型 | 基准档 |
|---|---|---|---|
| 1 | 超市开始限购鸡蛋 | 匮乏 | 石 |
| 2 | 办公室流感 | 疫病 | 石 |
| 3 | 小区跳闸一晚 | 气候 | 石 |
| 4 | 楼道电动车被偷 | 动荡 | 石 |
| 5 | 抢购潮 | 匮乏 | 铜 |
| 6 | 暴雨内涝 | 气候 | 铜 |
| 7 | 高温停电 | 气候 | 铜 |
| 8 | 新病毒上新闻 | 疫病 | 铜 |
| 9 | 裁员潮 + 银行限提 | 匮乏 | 银 |
| 10 | 小区封控 | 疫病 | 银 |
| 11 | 第一次暴乱 | 动荡 | 银 |
| 12 | **末日降临（极寒）** | 气候 | **金** |

- 玩家在**年初就能看到这 12 条记忆**，但只显示类型和大致描述。
- **蝴蝶效应值** 0~100：主角做出偏离前世的大动作（救人、囤太多、暴露先知）会涨。结算时实际档位 = 基准档 ± 偏移，偏移概率随蝴蝶值上升；类型也有小概率变化。年份越后记忆越模糊（第 2 年只显示一半，第 3 年起只显示"有大事"）。

**顶住的方式（= 折卡）**：
1. **硬顶**：月末仓库里对应维度物资的总品质分 ≥ 危机分（物资 石1 铜2 银4 金8；危机 石2 铜4 银8 金16），结算时自动消耗其中约一半分值的物资。
2. **借力**：NPC 的危机技能（医生顶疫病、退伍兵顶动荡）。要求好感≥朋友且本周在你这边。消耗他的技能卡一次，推进他的剧情。
3. **剧情解**：完成本月专属剧情事件（例如 11 月"组织全楼互助群"顶住动荡）。

**顶不住的后果**：石 = 心态 -2、丢一批物资；铜 = 主角生病，下 2 周不能行动；银 = 家被洗劫 / 同住 NPC 受伤或离开 / 主角健康 -3；金 = **主角死亡，本世结束**。

### 3.2 一周做什么

- 地图 10 个地点：家、公司、超市、药店、五金/户外店、二手市场、小区群（线上）、快递站、医院、郊区农场。
- 每个地点 1~3 个可见事件（按月份/阶段/flag 刷新），事件有红槽（必填）与白槽（选填：物资/情报/NPC 加骰或改结果）。
- **主角一周只能进一个事件**。好感≥朋友的 NPC 可以单独被派去别的事件。
- **上班**是一个每周可选事件：去 = 领周薪；连续 3 周不去 = 被裁（失去稳定收入，但省出时间）。这是第 1 年最核心的取舍：**上班挣钱 vs 翘班囤货**。
- 事件耗 1~2 周，下周初结算，弹结果卡。

### 3.3 卡牌

所有东西都是卡，四档品质（石/铜/银/金）。

| 类型 | 说明 |
|---|---|
| **主角卡** | 唯一。4 属性 + 健康/心态。 |
| **人物卡** | 5 位可攻略 + 若干普通 NPC。有属性、好感、生死、位置、是否同住。 |
| **物资卡** | 6 维度：食物 food / 水 water / 药品 medicine / 能源 energy / 安全 security / 日用 daily。占 1~3 格。**食物/药品有保质期（按周）**，过期降一档，再过期变垃圾卡占位。 |
| **情报卡** | 一次性：看穿下月危机真实档位 / 延后一个月 / 修正记忆。 |
| **技能卡** | NPC 好感解锁，借力顶卡或加骰。 |
| **心情卡** | 恋爱线产物，本月加心态或加骰。 |
| **麻烦卡** | 负面卡：占仓库位或每周扣钱扣心态，必须用事件处理（房东涨租、前任、父母催婚打电话、同住者的家人）。 |
| **危机卡** | 见 3.1。 |

### 3.4 仓库、钱、消耗（第 1 年经济）

- 仓库初始 12 格，可扩（清储物间 +4、租邻居车位 +3、搬去老K仓库 +8）。
- 初始存款 30000，周薪 2500，房租每月 4000。
- **通胀**：每月物价 ×1.1（12 月约 ×3）；9 月起银行每周限提；第 2 年钱作废。→ 逼玩家前期把钱变成东西。
- 每周消耗：主角 1 食物 + 1 水；同住 NPC 每人 +1。缺了掉健康。

### 3.5 属性与检定

主角 4 属性，初始各 1~3，一年内成长：💪体力 strength / 🔧手艺 craft / 🧠头脑 mind / 💬魅力 charm。

**检定 = 掷（属性A + 属性B + 白槽加成）个骰子，每骰 50% 成功，数成功数：**
0 = 失败（石级结果/触发麻烦）；1~2 = 铜；3~4 = 银；≥5 = 金（可触发隐藏剧情）。
NPC 同进一个事件时属性相加。心态 <3 时所有检定 -1 骰。

### 3.6 恋爱

- 好感 0~100，5 档：陌生 0 / 熟人 20 / 朋友 40 / 暧昧 60 / 恋人 80。
- 涨法：一起进事件 +2~5；送他缺的物资 +5~10（**送出去就没了**）；专属剧情事件 +10~20。
- 解锁：熟人=来串门；朋友=技能卡 + 可派遣；暧昧=可邀请同住（带来他的物资、每周 +1 消耗、他的麻烦卡）；恋人=借力顶卡 + 专属结局。
- **多线**：允许。同时 2 人≥暧昧触发"修罗场"事件（魅力+头脑检定）：失败双双 -20 且其中一人可能离开；大成功进入"默契"状态（后续可走多人结局）。
- **NPC 有生死**：银/金危机失败、某些事件失败会让 NPC 受伤→死亡。死亡永久，触发哀悼事件与心态惩罚。

### 3.7 首批可攻略角色（5 人，先做 3 人：阿哲、林晚舟、老K）

| 角色 | 身份 | 高属性 | 危机技能 | 缺 | 一句话 |
|---|---|---|---|---|---|
| 阿哲 | 隔壁程序员 | 头脑 | 情报（看穿下月危机） | 食物 | 社恐，末日了还在远程上班，其实什么都看在眼里 |
| 林晚舟 | 社区医生 | 手艺/头脑 | 顶疫病 | 能源 | 温和克制，超负荷工作，不信她的"预言"直到 8 月 |
| 老K | 退伍军人 / 保安 | 体力 | 顶动荡 | 药品 | 话少，靠谱，有不能说的过去 |
| 小鱼 | 便利店店长 | 魅力 | 补货折扣 | 安全 | 嘴甜，掌握全城货源八卦，机会主义者 |
| 陈序 | 网红主播 | 魅力/头脑 | 社区动员 | 水 | 表面浮夸，实际最会组织人 |

### 3.8 主角状态

健康 0~10（饿冷病掉，归零死亡）；心态 0~10（危机失败、孤独、麻烦卡掉，<3 检定 -1 骰）；声望 0~100（小区口碑，影响以物易物汇率与社区线）；蝴蝶效应 0~100。

### 3.9 第 1 年结局（年末结算，同时作为进入第 2 年的存档）

12 月"末日降临"是金卡，结果分档：
- **死亡**：没顶住 → 本世结束 → 重生画面，解锁记忆碎片。
- **独活**：顶住，无恋人。
- **双人 ×3**：与某人恋人档 + 同住 + 顶住。
- **多人**：≥2 人恋人档 + 默契状态 + 顶住。
- **社区**：声望 ≥80 + 顶住（可叠加）。
第 1 年结算画面显示：存活人员、仓库、属性、蝴蝶值 → 这些直接带入第 2 年。

### 3.10 多周目（重生循环）

每次死亡或通关解锁"记忆碎片"，下一世可选开局：+4 格仓库 / 某 NPC 初始好感 +20 / +1 属性点 / 一张情报卡。这就是标题的"重生"。
