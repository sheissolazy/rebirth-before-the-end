## 现状
`src/ui/` 已有一套能玩通的朴素界面（Claude 写的，纯 Tailwind、无动效、用 `<select>` 放卡）。引擎在 `src/engine/impl/`，内容在 `src/content/`。先 `npm run dev` 玩一局熟悉流程。

## 目标
把它做成"想一直玩下去"的样子。移动优先（~400px），深色，末日日记感。

## 要做
1. **地图页**：把地点按 `LocationDef.pos` 摆成真正的地图（序章是城市，末日后是"基地 + 外出"两层），地点上显示本周事件数角标；点地点弹底部抽屉列事件。
2. **事件面板**：卡槽做成真正的槽位（红槽/白槽），候选卡以卡面形式横向滚动，点选或拖拽放入；检定预览显示骰子数与四档概率；结算时有掷骰动画。
3. **卡面**：统一卡面组件，四档稀有度颜色（白/绿/蓝/金）、图标、份数、过期倒计时、词缀角标。
4. **顶栏**：时间、钱/晶核、健康、暴露、防御、危机进度条；序章倒数要有紧迫感。
5. **周结算**：新闻 → 事件结果 → 消耗 → 危机结果 分段展示，可逐条点过。
6. **人物页**：男主卡带立绘占位、好感条、档位；伙伴派工用图标按钮。
7. **基地页**：模块做成格子图，已建/损毁/可建三态。
8. **开局与重生**：死亡画面"再一次睁开眼"要有仪式感；重生点商店做成卡片。
9. 所有文字继续走 `t()` / `lt()`；缺的 key 往 `src/i18n/zh.ts` 加。

## 不要做
- 不改 `src/engine/`。需要引擎新增数据（例如"四档概率"），在 `docs/tasks/` 开任务给 Claude，或先在 UI 里用 `engine.previewDice` 自己算二项分布。
- 不加新数值系统。

## 验收
`npm run build && npm test` 通过；`node scripts/e2e.mjs` 仍能走通（选择器可以改）；手机宽度无横向滚动。
