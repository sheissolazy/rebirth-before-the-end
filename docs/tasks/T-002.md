## 目标
用假引擎把"一周的完整操作流"在浏览器里走通：看地图 → 点地点 → 点事件 → 往卡槽放卡 → 点"过一周" → 看周结算弹窗 → 回到地图。

## 要做
1. `src/engine/mock.ts`：实现 `GameEngine` 接口的假版本。`newGame` 返回一个手工构造的 `GameState`（用 `src/content/index.ts` 的样例内容），`endWeek` 只推进时间并返回一个假 `WeekReport`，`place/unplace` 维护 `state.placements`。**不要写真规则**。
2. `src/ui/` 页面（移动优先）：
   - `MapPage`：按 `LocationDef.pos` 摆地点；顶栏：时间 `t('time.format')`、存款、健康/心态、危机进度条。
   - `LocationSheet`：底部抽屉列出该地点的 `availableEvents`。
   - `EventPanel`：事件文案 + 卡槽（红槽必填）+ 候选卡列表（来自 `eligibleCards`）+ 检定预览（掷几个骰子）+ 放入/撤回。
   - `WarehousePage`：格数占用、按维度分组、过期倒计时、丢弃。
   - `PeoplePage`：NPC 卡、好感条、档位、同住/受伤/死亡状态、送礼入口。
   - `CrisisPanel`：本月危机卡 + 12 条记忆预告（`state.forecast`）。
   - `WeekReportModal`：`WeekReport` 的新闻、事件结果、消耗、过期、月末危机结果。
   - `DiaryPage`：`state.diary`。
3. 状态管理用 `useReducer` 或 zustand（自选），engine 通过 props/context 注入，方便之后换成真引擎。
4. 所有文字走 `t()` / `lt()`。缺的 UI key 往 `src/i18n/zh.ts` 加。

## 验收
- `npm run build && npm test` 通过。
- 手机宽度下无横向滚动。
- 把 mock engine 换成真引擎时，UI 代码不需要改（只换注入的对象）。
