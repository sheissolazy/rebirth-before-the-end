# 2.5D 原型试玩清单（2026-10-09 早上）

打开 https://sheissolazy.github.io/rebirth-before-the-end/proto/ ，如果还是旧版就 Cmd+Shift+R 强制刷新一次。第一次会弹欢迎卡（游戏先暂停）。

## 10 分钟能看完的路线

1. 点"先过日子"。看一家人吃早饭（7 点饭点同桌、会聊天说话）、有人去拿水、在院子里溜达。左边是"末日前要做的事"清单。
2. 按 3 切到三倍速。大概率上午就会有人来敲门——青梅竹马**江野**。选"把末日要来的事告诉他"。
3. 点左上"🗺 地图" → 超市 → 选两个人 → 出发。看他们走出铁门，几个小时后抱着纸箱回来。
4. 点二楼书桌上的红本子（或"📕 重生日记"）：倒计时、前世记忆（越往后越模糊）、认识的人。
5. 用 WASD 让女主走出铁门（镜头切成跟拍），绕到院子后面的江边钓鱼（E）。
6. 右下"原型调试" → "☠ 跳到月底危机夜"。看一大群丧尸攻铁门：点一个人再点地上的守位圈可以换位置，横幅上可以扔燃烧瓶。22 点以后留意铁门对面的街边。
7. 打完看战报。第二天白天爸爸会去修门。

## 想听你的意见

- **画面**：真人（MakeHuman）+ Poly Haven 的世外桃源风，你觉得人物搭不搭？丧尸够不够吓人？
- **节奏**：一天 = 现实 5 分钟，序章 4 天（20 分钟）。太快还是太慢？
- **难度**：子弹是最关键的物资。第一个危机夜（10 只）满子弹基本守得住，子弹少就会破门。合适吗？
- **男主**：现在 3D 里有江野（来访 + 危机夜来帮忙）、沈砚（有人重伤时来）、顾沉（军区）、谢临（只塞纸条）。你最想先把谁做深？
- **还没做的**：猫/狗（找不到风格搭的免费模型）、地盘扩张（占隔壁空房子）、出门结算接上文字版引擎。先做哪个？
