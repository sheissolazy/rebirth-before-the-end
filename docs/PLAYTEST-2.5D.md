# 2.5D 原型试玩清单（2026-10-09 早上）

打开 https://sheissolazy.github.io/rebirth-before-the-end/proto/ ，如果还是旧版就 Cmd+Shift+R 强制刷新一次。第一次会弹欢迎卡（游戏先暂停）。默认是世外桃源画风（真人模型都在这个画风里），右上角"画风"按钮可以切到卡通；如果你之前手动选过卡通，点一下切回来，或者打开 `…/proto/?style=paradise`。

## 今天上午新加的（先看这几样，5 分钟）

1. **🚐 面包车**：院子西南角停着一辆黄白两色的旧面包车（车牌"囤A·0001"）。点"🗺 地图"选个地方（比如超市），勾上"🚐 开面包车去"→ 出发：派去的人走到车门边上车，铁门往外推开，车拐出去开走；回来时从街西头开过来、**倒车进院子**，车顶绑着纸箱和一桶油，人下车扛着箱子进客厅。开车快四成、多装一半、烧 1 桶汽油（左上 ⛽）。没油了去新地点**加油站**。
2. **🐈 大橘**：客厅地毯上的橘猫。它会自己溜达、跟着女主、跑去挨着坐着的人趴下、找地方打盹，晚上去二楼床边睡。**点它**会喵一声、呼噜呼噜，冒 💕。
3. **人更自然、更聪明**：走路有脚跟脚尖、胯和肩膀的扭动；站着会抱胳膊、叉腰、挠头、伸懒腰、东张西望；聊天时会比划、点头；两个人迎面走来会让路。车开回来时，家里闲着的人会走到院子里挥手（"回来啦！"）；饭做好了有人喊"开饭啦！"，晚上说晚安，早上打招呼。
4. **🧸 Q 版人物**：右上角"人物：真人"按钮点一下，所有人（一家三口、四个男主、王阿姨、陌生人、丧尸）都换成 Blender 捏的 Q 版，再点一下换回来（会刷新一下，进度不丢）。**最想听你说：真人和 Q 版喜欢哪个？**

## 10 分钟能看完的路线

1. 点"先过日子"。看一家人吃早饭（7 点饭点同桌、会聊天说话）、有人去拿水、在院子里溜达。左边是"末日前要做的事"清单。
2. 按 3 切到三倍速。大概率上午就会有人来敲门——青梅竹马**江野**。选"把末日要来的事告诉他"。
3. 点左上"🗺 地图"（或按 M）→ 超市 → 选两个人 → 出发。看他们走出铁门，几个小时后抱着纸箱回来。（去一趟五金店会带回一把弩给爸爸。）
4. 点二楼书桌上的红本子（或"📕 重生日记"）：倒计时、前世记忆（越往后越模糊）、认识的人。
5. 用 WASD 让女主走出铁门（镜头切成跟拍），绕到院子后面的江边钓鱼（E）。左上还能开菜地 🌱、在铁门外铺钉板 🪤、把木围栏换成石头院墙 🧱、用 ✨ 空间把吃的藏起来。右上 📷 可以拍一张不带界面的照片。
6. 左上点"🪤 铁门外铺钉板"，再到右下"原型调试" → "☠ 跳到月底危机夜"。看一大群丧尸攻铁门（踩在钉板上的会变慢、一直掉血）：点一个人再点地上的守位圈可以换位置，横幅上可以扔燃烧瓶，有人被扑倒就点他的卡用急救包救起来。22 点以后留意铁门对面的街边。
7. 打完看战报。第二天白天爸爸会去修门。**危机夜要是没守住，会失去一个家人。**
8. 原型调试里还能叫：顾沉送一箱东西 / 谢临塞纸条（他们会真的走到铁门外）、顾沉上门借人、谢临傍晚站到门外、门外的陌生人（每次长得不一样，可以请 TA 住进来）。"🎚 难度"可以切到困难模式对比。最后一个按钮可以看看"女主死了"那一屏（能用重生点买下一世的开局加成，会进入第 2 世、重新开始）。

## 想听你的意见

- **画面**：真人（MakeHuman）+ Poly Haven 的世外桃源风，你觉得人物搭不搭？丧尸够不够吓人？
- **节奏**：一天 = 现实 5 分钟，序章 4 天（20 分钟）。太快还是太慢？
- **难度**：子弹是最关键的物资。模拟下来：第一个月尸潮有 12 发以上子弹能守住，6 发会失守死人；第三个月光靠一家三口守不住，要拉人入伙、等江野来帮忙。右下调试里有"困难模式"可以对比。太狠还是刚好？
- **男主**：现在 3D 里有江野（来访、危机夜来帮忙、好感高能住下来）、沈砚（有人重伤时来、疫病后送药、也能住下来）、顾沉（送物资、上门借人）、谢临（塞纸条、某个傍晚露面一次）。你最想先把谁做深？
- **生死**：饿死大约要 25 个游戏小时（1 倍速 5 分钟）、危机夜输了一定死一个家人、女主死了从头再来（重生点商店是我先定的第一版）。太狠还是刚好？
- **还没做的**：猫/狗（找不到风格搭的免费模型）、地盘扩张（占隔壁空房子）、出门结算接上文字版引擎、男主的长线剧情。先做哪个？
